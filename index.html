Tally

Customer Balances from Tally

Payment Updated, Payment Reminder and Balance Confirmation fill in both balances when you pick a customer, on every device. With the Chittam Enterprises Windows app running on the Tally PC (Tally Sync → Sync settings) these update by themselves every 30 minutes; otherwise import each company's file below.

  1. In Tally, open the company and go to Display More Reports → Account Books → Group Summary → Sundry Debtors.
  2. Press Alt+F5 (Detailed) so every customer is listed.
  3. Press Ctrl+E (Export) → File Format JSON (or XML) → Export.
  4. Import that file below for the same company, then repeat for the other company (F3 to change company).
